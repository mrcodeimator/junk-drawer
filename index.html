Junk Drawer

v0.9.1

Quick search for Filters, Adjustments, and Layer Styles.

Shortcut Setup Walkthrough

  1. Click Save Shortcut File… below and save Junk Drawer.jsx into your Photoshop Presets/Scripts folder.
  2. Restart Photoshop so it loads the new script.
  3. Click Open Keyboard Shortcuts (or go to Edit → Keyboard Shortcuts…), expand File → Scripts → Junk Drawer, and assign Ctrl+Shift+Space.
